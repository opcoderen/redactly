    怎么用

    打码：选工具（色块/马赛克/模糊/隐藏/画笔），在空白处拖拽即生成块；参数在工具条上调。
    编辑：点任意块选中 → 拖动移动、拉四角缩放、工具条「删除」；选中后换工具或调参数 = 改这个块的样式。
    自动识别：点「识别」自动找手机号/身份证/座机/邮箱/银行卡/发票号/统一社会信用代码/客票号/金额/日期/机读码/车牌，以及人脸（自动盖笑脸）。
    单据/证件场景：认出「门诊号 / 病历号 / 发票号 / 客票号 / 电话」等标签后，自动打它右边或下方的值；「姓名」标签后的中文名或拼音（登机牌 ZHANG SAN）也会打。
    手势：双击文字行 = 整行打码（再双击还原）；右键 = 精确到字。
    「完成」是提交键：画完一个块 / 放完笑脸后会自动选中并进入编辑态，此时只能编辑这一个对象（拖动、拉角、滑块、换工具改样式），想加新东西必须先点「完成」（或「删除」，或轻点空白 = 取消选中，Esc 同样可提交）。
    笑脸：选「笑脸」工具 → 点画布放置 → 拖动移位置 → 工具条「大小」滑块调尺寸 → 双击删除 → 点「完成」退出。选中时气泡会提示当前选中的是什么。
    隐私：所有处理均在浏览器本地完成，图片不会上传。支持常见图片 / HEIC（iPhone）/ PDF（按页处理）；高清大图自动降采样识别。
    部署：这是纯静态页面，可直接放到 Cloudflare Pages，也可用 Docker 在内网私有化运行。点顶部「可部署在 Cloudflare Pages」看命令。

    隐私 & 部署

    图片从不离开这台设备

    • 文字识别（OCR）跑在浏览器内的 WebAssembly 引擎上，模型文件随页面一起下发。
    • 人脸检测用本地权重，不调用任何云端接口。
    • 打码和导出走 Canvas，导出的 PNG 直接由浏览器保存，不经过服务器。
    • 整站没有后端、没有数据库、没有埋点，也没有任何 fetch 到第三方的代码。

    30 秒自己验证

    打开开发者工具 → Network → 上传一张图片 → 点「识别」。除了同源的模型文件，不会出现任何外发请求。页面的 CSP 里写死了 connect-src 'self'，浏览器会直接拦掉越界的请求，这一点不用信我们怎么说。

    自己部署

    Docker（内网 / 私有化 / 断网可用）

    docker run -d -p 8080:80 opcoderen/redactly

    Cloudflare Pages（免费、全球 CDN）

    Fork 仓库 → Pages 连接 GitHub → 构建命令填 node scripts/fetch-vendor.mjs、输出目录填 public。纯静态，无需环境变量和后端。

    模型文件较大（约 40MB），首次识别会慢几秒，之后走浏览器缓存。
